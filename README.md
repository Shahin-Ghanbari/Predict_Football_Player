# Football Injury Analysis

A Jupyter notebook project on football player injuries, with injury records, match data, and player statistics.

## Explore the project

Start with [Football_Injury.ipynb](Football_Injury.ipynb). You can preview it on GitHub or open it in Jupyter locally. Keep the CSV files in the same project folder when working with the notebook.

| File | Contents |
| --- | --- |
| [`injuries.csv`](injuries.csv) | Injury records |
| [`match.csv`](match.csv) | Match data |
| [`player_stats.csv`](player_stats.csv) | Player statistics |

The notebook is the starting point for the analysis. A reproducible environment and an end-to-end run have yet to be verified.
